Image prompts, once in a blue moon.

Fourteen photographs for the demo homepage. They are placeholders until the studio shares real work. Never generate images of real people.

  1. Open a new ChatGPT chat for each image.
  2. Press Copy prompt, paste it, and generate.
  3. Download the PNG and save it with the exact filename shown into image-inbox/.
  4. When a few are in, run npm run images (or tell Claude). The site picks them up automatically.
